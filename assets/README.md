# 브랜드 에셋

| 파일 | 용도 |
|---|---|
| `logo.svg` / `logo.png` (1024²) | 로고 · 앱 아이콘 · 조직 아바타 |
| `banner.svg` / `banner.png` (1280×640) | 조직 프로필 · 소셜 미리보기 |

- 로고 컨셉: **두리번** — 주변을 두리번거리는 눈
- 로고타입: 한글 "히어지", 굵은 고딕(Pretendard ExtraBold 기준), 자간 좁게
- 브랜드 컬러: 잉크 `#191F28`
- 텍스트: `#191F28` (진한 글씨), `#8B95A1` (보조 글씨)
